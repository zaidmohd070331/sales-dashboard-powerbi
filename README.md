# Sales Performance Dashboard — Power BI

## 📊 Project Overview
An interactive sales dashboard built in Power BI analyzing
retail sales data from 2015–2018 across the United States.

## 🛠️ Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (M Language)
- Python (Pandas) — data cleaning

## 📌 Key Insights
- Total revenue of $2.26M across 4,922 orders
- Technology is the top-selling category
- Consumer segment accounts for 50.79% of sales
- Average delivery time is 4 days

## 📁 Dataset
Superstore Sales Dataset — 9,994 rows, 18 columns
